# Documentation

## Purpose

This folder contains general documentation for the entire YouTube production repository.

## Document Types

### Guides
- Getting started guides
- Workflow documentation
- Best practices

### References
- Terminology glossaries
- Tool documentation
- API references

### Policies
- Content guidelines
- Quality standards
- Release procedures

## Key Documents

### For New Contributors
1. `/README.md` (root) - Repository overview
2. `/series/AION_Forge_and_Fracture/README.md` - Series specifics
3. This folder's guides

### For Production
1. Series-specific documentation in `/series/[series]/documentation/`
2. Asset guidelines in `/assets/README.md`
3. Configuration docs in `/config/README.md`

### For Development
1. Script documentation in `/scripts/README.md`
2. Tool setup guides
3. Environment configuration

## Documentation Standards

### Format
- Markdown (`.md`) for all documentation
- Clear headings and structure
- Code blocks with language specification
- Links to related documents

### Maintenance
- Keep docs updated when workflows change
- Deprecate outdated documents (mark clearly, don't delete)
- Include "last updated" dates on time-sensitive docs

### Style
- Clear, concise language
- Active voice
- Examples where helpful
- Screenshots/diagrams when they add value
