# Assets Repository

## Purpose

This folder contains shared media assets for all Sheldon K. Salmon YouTube productions.

## Folder Structure

### `/branding/`
Channel and series branding materials:
- Logos (PNG, SVG)
- Color palettes
- Typography guides
- Brand style guide
- Channel art

**AION: Forge & Fracture Palette:**
- Indigo (primary)
- Cyan (accent)
- Periwinkle (secondary)

### `/thumbnails/`
Thumbnail source files and templates:
- PSD/canva templates
- Font files
- Icon libraries
- Stock photo references

**Rule:** Lead with Part 4 (Red Team) moments even on earlier parts' thumbnails.

### `/music/`
Royalty-free and no-copyright audio:
- Background music tracks
- Sound effects
- License documentation
- Source attributions

**Requirement:** Free-tier compatible sources only until channel funds upgrades.

### `/templates/`
Reusable production templates:
- Video intro/outro
- Lower-third graphics
- Caption styles
- Overlay packages
- End screen templates

## Asset Standards

### File Naming
```
[Series]_[AssetType]_[Version].[ext]
Example: AION_Logo_Primary_v1.png
```

### Version Control
- Always version assets (v1, v2, v3)
- Never overwrite previous versions
- Mark deprecated assets clearly

### Licensing
- All assets must be free-tier compatible or properly licensed
- Maintain license documentation for each asset
- Track attribution requirements

## Tools

| Asset Type | Recommended Tool |
|------------|------------------|
| Graphics | Free tier design tools |
| Music | Royalty-free libraries |
| Templates | CapCut free tier |
