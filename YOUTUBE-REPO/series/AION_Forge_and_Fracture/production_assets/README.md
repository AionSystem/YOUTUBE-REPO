# Production Assets

## Purpose

This folder contains raw production materials for AION: Forge & Fracture episodes.

## Asset Types

### Raw Footage
- Original OBS Studio recordings
- Screen capture files
- B-roll or supplementary footage

### Project Files
- CapCut project files (free tier)
- OBS scene collections
- Template projects

### Exports
- Rendered video files
- Different resolution variants
- Platform-specific exports

### Graphics
- Overlay templates
- Lower-thirds
- Callout graphics
- Caption styling

## Color Palette (AionSystem)

The series uses a fixed visual template tied to the existing palette:
- **Indigo** - Primary brand color
- **Cyan** - Accent/highlight
- **Periwinkle** - Secondary accent

## Workflow Notes

1. Record in part-sized units (one AI session = one video part)
2. Keep chat and reference documents visible on screen
3. No voice — on-screen text carries the content
4. Add at least one caption/callout at the strongest moment (especially Part 4)
5. Logo overlay added consistently across all videos
