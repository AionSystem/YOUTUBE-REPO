# Episode Template Placeholder

This folder will contain all episode-specific content.

## Folder Structure for Each Episode

```
EP[NUMBER]_[EPISODE_NAME]/
├── raw_footage/          # Original screen recordings
├── project_files/        # CapCut/OBS project files
├── exports/              # Rendered video files
├── captions/             # SRT/caption files
├── thumbnails/           # Episode-specific thumbnails
└── notes/                # Production notes, scripts
```

## Episode Naming Convention

- Format: `EP001_DomainName_PartN_PartName`
- Example: `EP001_GameDesignDoc_Part4_RedTeam`

## Checklist

- [ ] Domain selected and classified (low/high stakes)
- [ ] Part number identified (1-5)
- [ ] Recording completed
- [ ] Editing completed
- [ ] Captions added
- [ ] Thumbnail created
- [ ] Metadata prepared (title, tags, description)
- [ ] Red team findings documented (if Part 4)
