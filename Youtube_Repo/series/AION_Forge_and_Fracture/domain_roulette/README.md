# Domain Roulette System

## Purpose

This folder contains the domain selection mechanism for AION: Forge & Fracture episodes.

## Selection Process

### Step 1: Generate 8 Candidate Domains

Generate 8 domains spread deliberately across different areas:
- Trades/maker work
- Healthcare or frontline service jobs
- Retail/everyday logistics
- Hobbies
- Software/digital
- Civic or community systems
- Food/hospitality
- Creative/entertainment

**Rule:** Exclude the last 1-2 domains used (no repeating back-to-back).

### Step 2: Random Selection Input

Ask for ONE real-world random input to pick from the 8:
- A number 1-8
- The last digit of the current time
- Any spontaneous external input

**Never** let an AI pick "randomly" on its own — it drifts toward obvious picks.

### Step 3: Classify the Domain

**Low-Stakes:**
- No real safety, health, legal, structural, or financial consequence if wrong
- Examples: games, productivity, hobbies, entertainment, creative
- Action: Build and sell freely

**High-Stakes:**
- Touches safety, health, legal, financial, structural, livelihood
- Action: Film it (honest content), but label explicitly as rapid draft/starting point if sold

### Step 4: Document the Selection

Record in this folder:
- Date of selection
- All 8 candidate domains
- Random input used
- Selected domain
- Classification (low/high stakes)
- Previous domains (to avoid repeats)

## Files

- `domain_log.md` - Historical record of all domain selections
- `candidates_template.md` - Template for generating new candidate lists
- `classification_guide.md` - Detailed classification criteria

---

*The unpredictability of domain selection is core to the series' authenticity.*
