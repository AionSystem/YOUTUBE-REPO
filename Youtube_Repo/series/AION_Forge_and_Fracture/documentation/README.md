## The Five-Part Pipeline

| Part | Name | On-Screen Requirement |
|------|------|----------------------|
| 1 | Idea Forming | Domain framing, fusion pass from multiple fields |
| 2 | Narrowing / Skeleton | Scope cuts, section headers, document bones |
| 3 | Build-Out | Actual drafting, skeleton filled in |
| 4 | Red Team | Finished draft tested, gaps found, live revision |
| 5 | Proof of Function | What it's for, how it'd be used/tested |

**Part 4 is the hook** — visible tension, something built then taken apart. Everything protects that part's quality first.

## Publishing Cadence

**Default:** One part per week
- Naturally matches one AI session per day
- Five-part series = five weeks
- Adjust based on tracking log data

## Key Principles

1. **No voice, no face** — Silent screen capture, text/captions carry content
2. **Build live** — Not narrating a large audit already done
3. **Domain rotation** — No repeating back-to-back
4. **Red team must find something** — Credible adversarial analysis
5. **Target domain audiences** — Metadata speaks to each domain's search space
